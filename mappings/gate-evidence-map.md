# Gate Evidence Requirements

> Last-Updated: 2026-04-08

| Gate | Phase(s) | Required Evidence | Responsible | Approver | Hard Stops |
|---|---|---|---|---|---|
| G1-A | 1–2 | C/B/P score worksheet, OFAC screening result, Project brief, Client rating | AM | NO | HS-01, HS-02, HS-04 |
| G2-A | 3 | Signed MSA, Payment schedule confirmed, Retainer received, FIN-001 billing setup | AM | NO, CFO (T2+) | HS-02 |
| G3-A | 4 | RACI-001 (named), PSF initiated, Kickoff minutes, Repository provisioned | PM | NO | — |
| G4-A | 5 | Threat model (4 categories), Admin/control matrix, Architecture diagram, DPIA (T2+ EU) | TL | **CISO (mandatory)**, NO | — |
| G5-A | 6 | 2 independent code reviews, Test evidence report (L3-TEST-204), SAST clean, Secret scan clean | TL, QA | CISO | — |
| G6-A | 7 | External audit decision memo, Bug bounty decision, Audit engagement letter (if applicable) | AM, CISO | NO | HS-03 |
| G7-IRR | 8–9 | Signing ceremony record (CL-411), Deployment runbook, Monitoring validated, All Crit/High resolved, Rollback plan | TL, DevOps | **CISO (mandatory)**, NO | HS-06, HS-07 |
| G8-A | 10–12 | Monitoring handover doc, Upgrade workflow, Client training, Knowledge transfer, Engagement close report | TL, PM | NO | — |
