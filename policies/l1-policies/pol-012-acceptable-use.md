## 1. Purpose

This Policy defines the acceptable and prohibited uses of Protofire information systems, networks, devices, and data by all authorised users. It establishes baseline behavioural expectations to protect Protofire's information assets and maintain a secure operating environment.

────────────────────────────────────────────────────────────

## 2. Scope

This Policy applies to all personnel (employees, contractors, consultants) and any individual granted access to Protofire-owned or Protofire-managed systems, including: workstations and mobile devices; email and messaging systems (Google Workspace, Slack); source code repositories (GitHub, GitLab); cloud infrastructure (AWS, GCP, Azure); development and staging environments; production systems and on-chain operations.

────────────────────────────────────────────────────────────

## 3. Acceptable Use Principles

### 3.1 Business purpose

Protofire systems are provided primarily for business purposes. Incidental personal use is permitted provided it does not interfere with work duties, consume excessive resources, or violate any provision of this Policy.

### 3.2 User accountability

Each user is accountable for all activity conducted under their credentials. Sharing credentials is prohibited. Users must lock or log out of unattended sessions.

────────────────────────────────────────────────────────────

## 4. Prohibited Activities

The following activities are strictly prohibited on Protofire systems:

### 4.1 Security violations

Attempting to bypass or disable security controls (MFA, access controls, monitoring); running port scanners, network sniffers, or penetration testing tools without written CISO authorisation; installing unauthorised software or browser extensions on corporate systems; connecting personal devices to production networks without CISO approval.

### 4.2 Data handling violations

Storing classified or sensitive data on personal devices or unapproved cloud services; transmitting client data, private keys, or credentials via unencrypted channels; sharing access credentials with any other person (including colleagues); copying production private keys to non-approved storage media.

### 4.3 Intellectual property violations

Using Protofire systems to infringe copyright, trademarks, or patents; reverse-engineering client or third-party software without contractual authorisation; disclosing Protofire proprietary code, processes, or client information without authorisation.

### 4.4 Legal and ethical violations

Using Protofire systems for illegal activity; accessing, storing, or distributing offensive, discriminatory, or harassing content; misrepresenting identity in communications; conducting personal commercial activities using Protofire resources.

────────────────────────────────────────────────────────────

## 5. Email and Messaging

Business communications must be professional and consistent with Protofire's values. Users must not: send bulk unsolicited messages; use Protofire email for personal commercial activities; forward internal security communications to external recipients without CISO approval.

────────────────────────────────────────────────────────────

## 6. AI and LLM Tool Usage

Use of AI/LLM tools (including Claude, ChatGPT, and similar) is permitted for business purposes under the following conditions: no client data, private keys, or credentials may be submitted to external AI services; no unreviewed AI-generated code may be committed to production repositories; AI tool usage for security-critical decisions must be reviewed by a human; all AI-generated content for client-facing deliverables must be reviewed and approved by the responsible human role. Detailed guidance is in GL-303 (AI &amp; LLM Tool Usage Guideline).

────────────────────────────────────────────────────────────

## 7. Remote Work and BYOD

Remote access to Protofire systems must use approved VPN or zero-trust access methods. Personal devices used for work must have: current operating system with security updates; disk encryption enabled; screen lock configured (maximum 5 minutes). BYOD devices must not be used for production signing operations.

────────────────────────────────────────────────────────────

## 8. Monitoring

Protofire reserves the right to monitor, log, and audit all activity on its systems. This includes email, messaging, file access, web browsing, and source code commits. Monitoring is conducted for security and compliance purposes in accordance with applicable law and POL-011 (data protection).

────────────────────────────────────────────────────────────

## 9. Enforcement

Violation of this Policy is subject to the disciplinary process defined in POL-015 §8. Serious violations (e.g., deliberate credential sharing, data exfiltration) may result in immediate access revocation and termination.

────────────────────────────────────────────────────────────

## 10. Review

This Policy is reviewed annually by the CISO.
